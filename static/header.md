## Overview 

This web application enables to compute the environmental impact of PV system for various settings of parameters.

It was automatically generated by [lca_algebraic web creator](https://git.sophia.minesparis.psl.eu/oie/lca_algebraic-web-app) 
based on the parametric inventory [Parasol LCA](https://github.com/oie-mines-paristech/parasol-lca).
